    Future Platform Development

    The current prototype focuses on analytics. Future versions could expand into broader project and data management workflows.

    Create & Manage Projects

    Planned / Future concept

    Future versions of the platform could allow authorised users to create and manage projects directly within YourQS Analytics.

    • Create a new project
    • Enter project attributes
    • Add construction scopes
    • Add cost items
    • Edit project information
    • Archive projects
    • Run analytics immediately after data entry
    • Benchmark newly created projects against historical data
    • Use What-if analysis during project planning
